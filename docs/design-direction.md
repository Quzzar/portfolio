# A quiet page with a secret terminal

The user approved mockup 3, `.impeccable/mocks/terminal-seed.png`: compact personal introduction, visible prompt, generous whitespace, and utility links at the bottom. They subsequently replaced the old software-engineer subtitle with three independent changing words, starting as founder, engineer, designer.

The word transition follows Prebreak’s `packages/project-intake/src/IntakeOpeningHeading.tsx`: fixed-height clipped lines and vertically sliding words. This page uses independent centered columns, slower staggered cycles, offscreen/hidden-page pausing, and a still reduced-motion version. The accessible identity stays “Founder, engineer, designer.”

Fira Code is self-hosted. It was the closest monospace face in the measured comparison against the comp. Light paper, blue-black ink, and steel secondary text keep the page quiet. The prompt is a real input, with a static block indicator before focus and the native caret while typing.

`work`, `about`, and `contact` are commands and clickable prompt suggestions. Clicking fills and focuses the input without running it; Enter executes. The terminal supports bounded history/transcript, unique Tab completion, unknown-command errors, themes, clear, and exit. It evaluates no JavaScript or operating-system commands. React escapes all visitor text.

`ls -a` reveals `./play`: an interactive monochrome ASCII wave surface. Pointer movement reshapes the field; a press makes a ripple. Back and Escape restore the terminal transcript and focus. A pause control and still reduced-motion path preserve control.

The user removed the identity pause control and requested centered words. Footer links read GitHub, Resume, LinkedIn. Both the theme button and theme command reveal the already-rendered opposite theme through six overlapping, randomly ordered brush strokes over 1250ms. Bristles vary per stroke, and direction, angle, and order vary per toggle. Native view snapshots expose text, controls, and background together, with no separate UI fade. The icon rotates and settles during the change. Reduced motion and browsers without view transitions switch immediately.

The project constellation was rejected in favor of the secret terminal. Centered calling-card and offset-note compositions were not selected. Avoid reintroducing them in later refinements.

Reference observations: Mobbin’s Locomotive hero separates utility links from the focal content; that separation informed the footer. The Aino and Metalab previews were blank and supplied no visual evidence. The approved image, followed by the user’s identity correction, is the visual authority.
