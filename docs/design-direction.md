This page uses independent centered columns, randomly rescheduled 3–6 second delays, offscreen/hidden-page pausing, and a still reduced-motion version. Fira Code is self-hosted. It was the closest monospace face in the measured comparison against the comp. Light paper, blue-black ink, and steel secondary text keep the page quiet. The prompt is an xterm.js terminal emulator with a block cursor, text selection, scrollback, and an incremental xterm-readline controller. No visible HTML input or ghost-completion row remains.

The work/about/contact navigation row is removed. Visitors type commands. Tab completes unique command names and filenames immediately. For ambiguous tokens it first lists choices without modifying the typed text; the next Tab selects the first match. Repeated Tab cycles those original matches; Shift-Tab cycles backward. Typing or moving the caret ends the completion cycle. Completion replaces the token at the caret and preserves following arguments. Arrow keys edit and recall history; Home/End and Ctrl-A/E move the cursor; Ctrl-C cancels a line; Ctrl-L clears; Escape leaves terminal focus. Enter runs the command. Output, including project URLs, is rendered by xterm, with the web-links addon handling destinations. The browser-only command vocabulary remains allowlisted. The emulator is loaded as a separate chunk and fits its column count and viewport to the screen. The page uses 100dvh and a compact top inset. The terminal fills the remaining space between header and footer and scrolls internally; typing, completion, and command output do not change page geometry. Terminal output does not pause the identity words. Help lists only commands. Other responses contain factual text, file names, or URLs without greetings, encouragement, or usage instructions. Refit occurs only when its actual dimensions or font size change. Terminal navigation keys suppress native page scrolling.

`ls -a` reveals `./play`: an interactive monochrome ASCII wave surface. Pointer movement reshapes the field; a press makes a ripple. Back and Escape restore the terminal transcript and focus. A pause control and still reduced-motion path preserve control.
