## Platform

web

## Product Purpose

Aaron Cassar’s personal website: a deliberately bare, beautifully polished introduction with a secret terminal and real commands. The user explicitly wants to embrace how little a conventional personal website matters and make something playful.

## Capabilities and Constraints

Keep the configured custom domain, aaroncassar.com, connected to GitHub Pages. Preserve genuine contact, GitHub, LinkedIn, résumé, and project destinations from the previous website. No invented employment status or metrics.

## Brand Commitments

Extremely minimal, coder-like, simple. Polish rather than volume. One surprising moment that can open into something more elaborate. Aaron identifies as a founder, engineer, and designer, rather than a software engineer. Three independent columns start with those words and change into builder, artist, creative, adventurer, maker, and explorer.

## Evidence on Hand

The previous homepage is available at git revision ec33aa1. It identifies Aaron as a software engineer and contains project links and contact details. The résumé is in public/resume/Resume.pdf. Current employment claims are unconfirmed.

## Open Decisions

Primary visitor audience is not specified. The user approved mockup 3 (visible terminal prompt), following their choice of a secret terminal and image mockups before implementation. Their later request for changing identity words supersedes the subtitle in that image. The original constellation proposal was rejected.
